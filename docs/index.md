# Database Learning Workspace

Use this workspace to learn relational database concepts and compare how they
are applied across MySQL, PostgreSQL, and SQL Server.

## Learning path

1. Start with [Database Concepts](database-concepts/index.md) for shared
   foundations such as schemas, keys, constraints, and transactions.
2. Explore [MySQL](MySQL/index.md), [PostgreSQL](PostgreSQL/index.md), and
   [SQL Server](sql-server/index.md) for engine-specific behavior.
3. Compare the same concept across engines and record differences in syntax,
   defaults, and operational behavior.

Each project owns its documentation so examples can grow alongside its code.
