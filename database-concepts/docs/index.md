# Database Concepts

This project is the shared foundation for the engine-specific projects.
Examples here focus on relational database ideas that apply across systems.

## Learning path

1. [The relational model](relational-model.md): understand relations, rows,
	columns, schemas, and data types.
2. [Keys and constraints](keys-and-constraints.md): identify records and
	enforce valid data.
3. [Relationships and normalization](relationships-and-normalization.md):
	model connections without unnecessary duplication.
4. [Queries and joins](queries-and-joins.md): retrieve and combine data.
5. [Transactions](transactions.md): reason about reliable concurrent changes.
6. [Indexes and query plans](indexes-and-query-plans.md): understand how
	systems find data efficiently.

Use the MySQL, PostgreSQL, and SQL Server sections to compare how each engine
implements these concepts.
